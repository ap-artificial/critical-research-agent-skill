# Critical Research Agent - Claude Skill

> A production-grade Claude Skill that forces AI to think critically before recommending company opportunities. Built with 5-pillar triangulation and anti-hallucination validation.

### The Problem
Most AI gives generic, hallucinated answers when asked "What is the opportunity to work with X company?" This damages credibility in client pitches.

### The Solution
This skill transforms Claude into a critical analyst that:
1. **Challenges assumptions** - Asks for target market, socio-cultural context, market conditions BEFORE answering
2. **Validates everything** - Every number needs source + confidence tag
3. **Triangulates** - Arithmetic, trend, source, and cross-pillar checks
4. **Thinks in phases** - Research brief first, deck only after approval

### Framework: 5 Pillars
1.  **Client Credentials** - Corporate snapshot, momentum, SoV
2.  **Market & Category** - Ad spend, channel mix, regulation (ID: halal, OJK)
3.  **Audience Voice** - Social, Tokopedia/Shopee reviews, Kaskus/Reddit, KOL discourse. Bahasa search included.
4.  **Variables & Geo Overlay** - Specific corridors (Sudirman-Thamrin, not just Jakarta), whitespace analysis
5.  **Fit Assessment** - Honest capability mapping

### Validation System
[triangulated] = ≥2 sources agree (strongest)
[verified] = multiple credible sources
[single-source] = one source, not cross-checked
[directional] = estimated
[claimed] = from subject itself
